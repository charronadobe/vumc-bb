# embed-video

Custom **embed** block. Purpose: Click-to-play video embed with poster image; supports Vidyard, YouTube and Vimeo.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one cell: optional poster image, then the video link (https://play.vidyard.com/<id>, YouTube or Vimeo URL).

## Supported variations

No variations.
